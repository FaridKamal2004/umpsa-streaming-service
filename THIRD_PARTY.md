# Film credits

The demo streams unmodified open films from Internet Archive media mirrors. Files are not bundled in the repository. Availability is controlled by the external host. Archive-generated MP4 encodings may differ in resolution and compression from the original masters; this application does not edit the film content.

Playback mirrors: [Sintel](https://archive.org/details/Sintel), [Big Buck Bunny](https://archive.org/details/BigBuckBunny1280x720Stereo), [Tears of Steel](https://archive.org/details/Tears-of-Steel), and [Elephants Dream](https://archive.org/details/ElephantsDream).

Blender's [open film collection](https://studio.blender.org/films/) provides project context. These credits do not imply creator endorsement.

Film descriptions are newly written summaries. Abstract mountain, sun, city, and orbit artwork is original CSS illustration and does not reproduce official film posters. The application uses system Arial/Helvetica and Georgia fonts; it makes no requests to a third-party font or icon service.

Development dependencies: Playwright (`@playwright/test`), Apache-2.0, and axe-core (`@axe-core/playwright`), MPL-2.0. These are used for testing and are not shipped in the static runtime.
